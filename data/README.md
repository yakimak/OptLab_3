# Данные варианта 1

**Источник:** синтетический кейс facility location, сгенерирован скриптом
`../generate_data.py`.

**Seed:** `10131 = 10000 + 100·Q + N`, где `Q = 1` (группа 517), `N = 31`.

**Файлы:**

- `candidates.csv` — 6 кандидатов: фиксированная стоимость, мощность,
  координаты;
- `clients.csv` — 8 клиентов: спрос и координаты;
- `transport.csv` — транспортные затраты 6×8;
- `params.json` — суммарные мощности/спрос, единицы, seed.

**Процедура генерации.** Фиксированные стоимости
`[800, 900, 700, 950, 850, 750]` тыс. руб., мощности
`[120, 100, 90, 110, 80, 100]` ед., спрос
`[50, 45, 60, 55, 40, 65, 50, 45]` ед. Базовые транспортные затраты 6×8
умножены на мультипликативный шум `N(1, 0.06)` и округлены до 0.01.
Координаты кандидатов и клиентов случайны и используются только для
визуализации; транспортные затраты заданы отдельной матрицей.

**Единицы:** поток и мощности — ед. груза; фиксированные и транспортные
затраты — тыс. руб. и тыс. руб./ед.

**Перегенерация:**

```bash
python generate_data.py
```
